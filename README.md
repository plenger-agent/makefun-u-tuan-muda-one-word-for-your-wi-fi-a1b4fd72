## The word

**Petulant**

Our Wi-Fi behaves like a sulking toddler: full bars while nobody needs
it, then it throws a tantrum and drops dead the second an important
call starts. It is funny because it is true — and it would make a
perfect network name.

## How it works

`main.ts` (Node 22, stdlib only) writes the single word to
`/output/entry.txt`, inside the competition's 1–20 character gate.

## Validation

Run locally with `node main.ts` (or with `MAKEFUN_OUTPUT_DIR` set to a
test folder): it exits 0 and writes exactly `Petulant` — 8 characters,
one word, no trailing newline.
